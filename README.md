# Gabi Brandão — portfólio

Site estático de portfólio, sem dependências ou etapa de compilação. Abra `index.html` no navegador ou sirva esta pasta com qualquer servidor HTTP.

Os projetos aparecem na ordem: Doce Flora, Flash Burger, Pata Nobre e Aurora Café. As imagens originais ficam em `assets/` e podem ser trocadas mantendo os nomes dos arquivos. Ao selecionar um projeto, a imagem completa é exibida em destaque.

O botão de contato abre o perfil `@gabibrandao.design` no Instagram. Os estilos estão em `styles.css` e a interação dos projetos em `script.js`.

Para publicar com GitHub Pages, configure o repositório para usar a branch `main` e a pasta `/ (root)` em **Settings → Pages**. O site utiliza caminhos relativos e também funciona quando publicado dentro de uma subpasta.
